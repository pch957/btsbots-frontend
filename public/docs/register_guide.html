🚀 第一步：安装极速 Python 工具 uv

BTSBots 采用现代化的 Python 工具包，建议使用 uv 进行极速安装与依赖同步：

# Linux / macOS 系统一键安装：
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows 系统（PowerShell）：
powershell -ExecutionUrl https://astral.sh/uv/install.ps1

📦 第二步：克隆仓库并初始化环境

git clone https://github.com/pch957/btsbots.git
cd btsbots

# 使用 uv 一键同步虚拟环境与依赖
uv sync

🔑 第三步：使用邀请码注册全新 BitShares 账号

运行官方注册引导程序，输入邀请码与心仪的账号名：

# 标准注册命令格式：
uv run registre_account.py --invite <您的邀请码>

# 示例：
uv run registre_account.py --invite BTS-9A4B8F21
  1. 本地生成私钥：程序将在您的本地电脑内存中安全生成 Owner、Active、Memo 三对椭圆曲线密码学公私钥。
  2. 链上委托注册：程序将公钥提交至您推荐人的 sign_bots 网关，由推荐人代为向比特股区块链广播开户操作并支付网络注册手续费。
  3. 生成本地凭证文件：注册成功后，您的本地同级目录下将自动生成形如 username_credentials.txt 的安全私钥凭证文件。

🛡️ 第四步：凭证管理与安全守护启动

注册完成后，本地生成的凭证文件格式如下：

myaccountname
Owner WIF: 5KQwrPbwdL6PhXujxW37FSSQZ1JiwsST4cqQzDeyXtP79zkvFD3
Active WIF: 5KQwrPbwdL6PhXujxW37FSSQZ1JiwsST4cqQzDeyXtP79zkvFD3
Memo WIF: 5KQwrPbwdL6PhXujxW37FSSQZ1JiwsST4cqQzDeyXtP79zkvFD3

1. 获取 8 位 OTP 登录 Web / App

uv run get_otp.py --keyfile myaccountname_credentials.txt

终端将输出一次性动态验证码，直接在网页端输入即可安全登入！

2. 启动本地签名守护网关

uv run sign_bots.py --keyfile myaccountname_credentials.txt

保持后台守护运行后，您即可在浏览器、手机 App 上随意发起安全转账、限价单交易与分红领取！

💡 附：比特股终生分红与推荐机制

  • 终生分成：新账户在比特股 DEX 交易所进行的所有交易（手续费返现与分红），其推荐人将终生共享手续费收益。
  • 无中心化托管：所有的分红收益均直接沉淀在比特股链上归属对象（1.13.x）中，您可以随时在 BTSBots 钱包的【🎁 分红】页面一键提取。
