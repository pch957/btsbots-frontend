🤖 BTSBots Smart Wallet & Decentralized Client - User Manual

Welcome to BTSBots! A decentralized DEX & Smart Wallet system built on BitShares featuring Zero-Trust Security Architecture.

🛡️ 1. Hardcore Security Mechanisms

Zero-Key Web Architecture

  • No Browser WIF Storage: Physical private keys never touch LocalStorage.
  • WebCrypto Session Signing: Uses browser-native ECDSA P-256 session keys to sign transaction intents.

In-Memory Key Sandbox Protection

  • AES Encrypted Buffers: WIF keys stay encrypted in RAM without touching disk.
  • Process Isolation: Uses Unix fork subprocesses, zeroing key buffers upon completion.

🔑 2. Key Management & Launch

# Launch with Unix pass store
uv run python sign_bots.py --pass bts/my_account

📱 3. OTP & Scan Integration

  • 8-Digit OTP: Fetch OTP via uv run python get_otp.py --pass bts/my_account for keyless web logins.
  • QR Schemes: Supports standard btsbots://transfer & btsbots://oauth URIs.
