📖 BTSBots 用户使用手册

1. 核心安全架构与防护体系

BTSBots 采用私钥不触网、零信任本地沙盒签名的设计模式：

  • 前端 Web / 移动端：只生成临时 WebCrypto 鉴权签名，不保存任何 BitShares 明文私钥。
  • 本地签名守卫 (sign_bots.py)：在独立沙盒进程中运行，每次签名后内存立即擦除。
  • IP 交叉核验：比对请求端与执行端公网 IP，防止跨网钓鱼。

2. 推荐运行方式 (使用 uv 与 pass)

# 1. 推荐使用 Unix pass 管理密码
pass insert bts/myaccount

# 2. 使用 uv 运行守护进程
uv run sign_bots.py --pass bts/myaccount

# 3. 获取 Web 登录 8 位 OTP 验证码
uv run get_otp.py --pass bts/myaccount

3. 5分钟自动锁屏保护

在【设置】中设定 4-6 位 PIN 码后，5 分钟无操作或切到后台自动锁定，保障设备资产安全。

📖 BTSBots User Manual

1. Security Architecture

BTSBots adopts a zero-trust, isolated local signing architecture with sandboxed process execution, WebCrypto session keys, and anti-phishing IP verification.

2. Running with `uv` and `pass`

# 1. Manage keys securely with pass
pass insert bts/myaccount

# 2. Run daemon with uv
uv run sign_bots.py --pass bts/myaccount

# 3. Retrieve Web OTP
uv run get_otp.py --pass bts/myaccount

3. 5-Minute Auto-Lock

Setting a 4-6 digit local PIN locks your dashboard automatically after 5 minutes of inactivity or background sleep.
