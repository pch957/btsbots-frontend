🔐 BTSBots 商户接入 OAuth 开发手册

1. 防护机制

  • 客户端 IP 比对：比对商户端与钱包端 IP，杜绝钓鱼。
  • 5 分钟一次性挑战码：Token 超时即作废。
  • 链上公钥验证：实时核验 Active 签名公钥。

2. 快速启动 (uv)

uv run biz_bots.py --pass bts/merchant_account
uv run biz_proxy.py --host 0.0.0.0 --port 9000 merchant_account BTS_PUBKEY
